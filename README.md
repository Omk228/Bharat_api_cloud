# 🇮🇳 Bharat API Cloud

An API ecosystem and management platform built with modern web technologies.

---

## 🏗️ Project Architecture

This repository contains both the Frontend client and the Backend services:

- **[`Frontend/`](./Frontend/)**: TanStack Start / React + TailwindCSS + Radix UI application.
- **[`Backend/`](./Backend/)**: Node.js + Express backend with MVC + Services architecture and MySQL database support.

---

## 🚀 Getting Started

### Backend Setup
```bash
cd Backend
npm install
# Configure .env with your MySQL credentials
npm run dev
```

### Frontend Setup
```bash
cd Frontend
npm install
npm run dev
```
